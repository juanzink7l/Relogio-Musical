# 🎶 Relógio Musical

Um relógio digital temático desenvolvido com **HTML, CSS e JavaScript**, que combina a exibição do horário atual com imagens relacionadas à música.

A cada minuto, o projeto altera automaticamente a imagem exibida, criando uma experiência visual diferente conforme o relógio avança.

> [!NOTE]
> Este projeto foi desenvolvido como uma aplicação front-end simples para praticar HTML, CSS e JavaScript.

## 🚀 Demonstração

🔗 **[Acessar o Relógio Musical](https://juanzink7l.github.io/Relogio-Musical/)**

## ✨ Funcionalidades

* 🕐 Exibição do horário atual em formato digital.
* ⏱️ Atualização automática do relógio a cada segundo.
* 🎵 Exibição de imagens relacionadas à música.
* 🔄 Alteração automática da imagem a cada minuto.
* 🎨 Interface com tema visual musical.
* 📱 Estrutura simples e leve para execução diretamente no navegador.

> [!TIP]
> O projeto não necessita de servidor ou banco de dados. Basta abrir a página no navegador.

## 📂 Estrutura do projeto

```text
Relogio-Musical/
│
├── index.html
├── script.js
└── style.css
```

### 📄 `index.html`

Responsável pela estrutura principal da aplicação, incluindo o título, o elemento que exibe o horário e a imagem temática.

### 📄 `script.js`

Responsável pela lógica do projeto.

O JavaScript:

* Obtém a hora atual através de `Date()`;
* Formata horas, minutos e segundos;
* Atualiza o elemento do relógio;
* Seleciona uma imagem com base no minuto atual;
* Atualiza o conteúdo automaticamente a cada segundo.

### 📄 `style.css`

Responsável pela aparência da aplicação, incluindo:

* Fundo temático;
* Fonte e alinhamento;
* Tamanho do relógio;
* Dimensões da imagem;
* Bordas e arredondamento da imagem.

## ⚙️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/juanzink7l/Relogio-Musical.git
```

### 2. Entre na pasta

```bash
cd Relogio-Musical
```

### 3. Execute

Como o projeto utiliza apenas HTML, CSS e JavaScript, não é necessário instalar dependências.

Você pode simplesmente abrir o arquivo:

```text
index.html
```

no navegador.
